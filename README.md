# Explainable Credit Risk Intelligence

## Business Problem
Develop an educational machine learning system that estimates
credit risk using a publicly available dataset.

## Objectives
- Analyze and validate structured data
- Build and evaluate baseline ML models
- Explain model predictions using SHAP
- Assess model errors and potential bias
- Track experiments and model performance
- Deploy the model through an API
- Monitor data drift and model performance

## Tech Stack
Python, Pandas, Scikit-learn, SQL, SHAP,
MLflow, FastAPI, Docker, GitHub Actions

## Current Status
Phase 1: Problem definition and repository setup.

## Limitations
This is an educational portfolio project and is not
validated for real-world credit approval decisions.
